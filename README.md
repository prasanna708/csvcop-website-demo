# CSVCOP website: demo for review

Two pages proposed for www.csvcop.com, shown here for review before they are built into the real site.

- **Products** (`products.html`): the two modules, 21 CFR Part 11 Controls and Micro-segmentation, side by side and with equal weight.
- **Home** (`index.html`): rebalanced so Micro-segmentation carries the same weight as 21 CFR Part 11 Controls.

Links to Overview, Features, Pricing, FAQ and Contact open the current live site. This demo is not the live site, and it asks search engines not to index it.

Plain HTML, CSS and JavaScript. `source/build.py` assembles the two pages from the parts in `source/`; it reads the icon set from the CSVCOP web application on the PC it runs on.
