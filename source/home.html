21 CFR Part 11 Controls

The configuration you applied is the configuration the machine has

The CSVCOP Watchdog runs as SYSTEM and starts before anyone signs in. Every half minute it compares the live state of each control with the encrypted master, restores what differs, and logs it as a tamper event.

  • Registry policy, security policy and user rights, in every user profile
  • Tells your own changes from tampering, so there are no false alarms
  • Restores its own master from a protected backup if it is deleted

Micro-segmentation

Rules made from what the PC really does

An instrument PC needs its data server, its instrument and Windows itself — not the whole network, and not the whole internet. Learning mode records every connection the PC makes, and each line becomes a rule in one click. Then isolate the PC from its network, limit the internet to named programs, or both.

  • Rules by program or Windows service, address, port and protocol
  • Presets for a file share, SQL Server, a printer and Remote Desktop
  • Schedules: a rule holds only during its window

Micro-segmentation

Safe to apply, held in place, on record

  • Rules changed outside CSVCOP put back and logged as tampering
  • Each refused connection recorded with program, address, port and protocol

How it works

From a fresh Windows PC to a locked, segmented, audited workstation

An application decides, a service enforces, an agent guards the session, and the firewall built into Windows carries the network policy.

01 · INSTALL

Install and activate

One MSI per workstation. A licence key bound to that PC activates it, with no internet.

02 · LOCK DOWN

Switch on the controls

Choose the controls your SOP asks for; each says what it does. Save & Apply asks for the password again.

03 · SEGMENT

Decide the connections

Learning mode shows what the PC talks to. Make the rules from what was seen, apply the restrictions, confirm them.

04 · PROVE

Print the evidence

Reports to PDF: the controls as applied, every change and who made it, the network policy and every refused connection.

Compliance

Built around what 21 CFR Part 11 asks you to show

CSVCOP supplies the workstation-level controls and writes the records. Your validation and SOPs remain yours — and become far easier to evidence.

Limited access

Windows policy for the workstation and password-policy, rate-limited CSVCOP accounts. § 11.10 (d)

Audit trails

Time-stamped entries with the account, written independently of the operator: tamper events, blocked attempts, refused connections. § 11.10 (e)

Operational checks

Controls and firewall rules that put themselves back every 30 seconds cannot drift between audits. § 11.10 (f)

Device checks

Removable-storage control with a whitelist by hardware identity. § 11.10 (h)
